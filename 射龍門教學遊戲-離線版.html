教學射龍門規則

每局每位玩家輪流一次，每局開始按目前分數由高到低排列，同分依設定順序。抽出門牌後才下注。

  • 一般門牌：進門加下注分數；撞柱加兩倍下注；門外扣下注分數。
  • 同點門牌：選擇押大或押小，猜中加下注分數，猜錯扣下注分數；撞柱加三倍下注。
  • 連號門牌：自動重新抽兩張門牌，不計入局數、不扣分。
  • 過牌：本局記 0 分。每位玩家完成後進入下一局。

A = 1、J = 11、Q = 12、K = 13。下注可自行輸入 1～1,000,000 的整數，不受目前分數限制，分數低於 0 即淘汰。每局開始重置為 52 張牌，局內抽出的牌不放回、不再出現。籌碼為 0 的玩家跳過；低於 0 的玩家淘汰；可在成績表調整籌碼，調回正數後從下一局重新加入。本局牌不足時結束遊戲。
