# GAMEpoke

繁體中文多人射龍門教學遊戲。直接開啟 index.html 即可離線使用，或透過 GitHub Pages 分享。

## 功能

- 玩家直排、局數橫排的成績表，可直接修改籌碼。
- 每局依分數排序，每局重置 52 張牌，局內不放回。
- 一般進門加一倍下注，撞柱加兩倍；同點門牌押大或押小，撞柱加三倍。
- 連號自動重抽；零籌碼跳過，負籌碼淘汰，調回正數後可再加入。
- 球場動畫、男性球員射門、守門員撲救與可切換音效。
- 全部資源內嵌，不需要網路、套件或建置步驟。

## GitHub Pages

在儲存庫 Settings → Pages，選擇 Deploy from a branch，設定 main 分支與 / (root)，儲存後即可使用公布的網址。

遊戲僅使用虛擬教學分數，不涉及真實金錢。
