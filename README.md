# GAMEPOKE! 歡樂遊戲大廳

線上遊玩：https://ruruguy.github.io/GAMEpoke/

十四款遊戲：射龍門、骰寶、抽獎球、幸運轉盤、變形德州撲克、搖籤筒、麻將聽牌練習、鱷魚拔牙、幸運爬梯、幸運拉霸機、加減乘除、十點半闖關挑戰、遊戲轉蛋機、撲克牌九宮格。

- 開啟 `index.html` 使用多檔版；開啟 `歡樂遊戲大廳-離線版.html` 可單檔離線遊玩十四款遊戲。
- 大廳分類、遊戲分頁、全螢幕；切換遊戲保留當次進度。
- 共用計時器：自訂分鐘與秒數、1／3／5／10 分鐘快捷鍵、開始／暫停／繼續／重設、時間到提示音；切換遊戲仍繼續計時。
- 抽獎球：自訂組別、顏色、票數、搖動音效與 CSV 紀錄。
- 籤筒：搖動、伸手挑籤與抽出動畫。
- 爬梯子：拖拉起跑點、追逐鏡頭、單組／依序／同時出發。
- 拉霸機：依權重產生圖案帶，按停止鎖定中央圖案，三輪相同中獎，搭配慶祝音效與動畫。
- 拉霸機考試模式：三類止血包紮題目各抽一項，學員編號、放大題目、獨立紀錄及 CSV 匯出。
- 抽獎球、爬梯設定與拉霸紀錄保存在目前瀏覽器；虛擬籌碼皆為教學分數。

圖案為題目識別示意；考核內容依授課者的既定標準進行。

- 加減乘除：自訂 1～30 位玩家與初始籌碼，加／減／乘／除四局，開始時依起始分數排序，每位玩家完成四次運算再換下一位，除法保留兩位小數，完賽最高分者顯示皇冠。

- 十點半闖關：起手一張，最多五張；一般勝出淨贏 1 倍、十點半 2 倍、五張未爆 2 倍、五張花牌 5 倍，另退本金；同點牌少者勝出，同點同張數退本金。點手牌付 1 籌碼換牌，老師操作莊家 PK，每局重洗牌。

- 遊戲轉蛋機：自訂增減獎項、等機率選取、扭蛋與放大揭曉、不重複選項、全螢幕、音效、本機紀錄與 CSV 匯出；只揭曉選項，不自動啟動遊戲。

- 撲克牌九宮格：每位玩家籌碼 1～43 代表挑戰牌張數，每人重新洗牌，選格猜大／小；A=1、J=11、Q=12、K=13，猜對加 1 分，同點不得分，新牌取代該格，完賽最高分者戴皇冠。
